# Sodimac Media Sales Planner React

## Ejecutar
```bash
npm install
npm run dev
```

El proyecto consume `src/config/sales_planner_config_v2.json`. Sustituye ese archivo por el JSON completo adjunto, conservando la misma estructura.

## Reglas incluidas
- Brief y objetivo separados.
- Objetivo precarga AW/CO/PE; modo manual suma 100%.
- Score por pesos del JSON.
- CRM obligatorio como formato real.
- Google y Meta agrupados solo en presentación.
- Respeto de mínimos `min`.
- Benchmark al pie y disclaimer.
